# Прогнозирование свойств композиционных материалов

Выпускная квалификационная работа (МГТУ им. Н.Э. Баумана, Центр НТИ «Цифровое материаловедение»).

## Структура проекта
- `data/` - исходные и предобработанные датасеты
- `notebooks/` - Jupyter Notebook с EDA, обучением ML-моделей и нейронной сети
- `models/` - сохраненные модели и скейлер
- `docs/` - графики, таблицы метрик и пояснительная записка
- `app.py` - веб-приложение на Streamlit
- `requirements.txt` - список зависимостей

## Запуск
```bash
pip install -r requirements.txt
streamlit run app.py
```
